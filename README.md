# Jammeh AsSalaam Moving

Local Next.js recreation of https://jammeh-moving.blackwood4884.chatgpt.site/.

## Run

```sh
npm install
npm run dev
```

Open http://127.0.0.1:3000. The development command uses Webpack to avoid a macOS Turbopack file-watcher failure in restricted environments. If your environment restricts native file watching, use `WATCHPACK_POLLING=true npm run dev`.

## Production

```sh
npm run build
npm start
```

## Structure

- `app/page.tsx`: page content, mobile navigation, and FAQ controls.
- `app/move-planner.tsx`: local move summary, clipboard copy, text download, and editing.
- `app/globals.css`: original responsive styling.
- `public/`: locally hosted reference image and favicon.

The planner does not transmit information or book a move. Data remains in browser memory and clears on reload. Returning to edit preserves entered details.

## Local SEO

The primary public domain is `https://jamoving.co`, and the public phone is `(415) 940-5405`. The homepage and `/east-bay-moving-services` each have a unique title, description, canonical URL, and social metadata. Server-rendered JSON-LD describes the business, service area, and service-page breadcrumbs. `/sitemap.xml` and `/robots.txt` are generated by Next.js.

`lib/site.ts` centralizes the business data used by metadata and structured data. An optional `SITE_URL` environment variable overrides the production origin for a domain migration; use an absolute HTTPS origin and rebuild. The current version remains a business launch preview until operational status is confirmed. The move planner does not submit leads; customers can call the published number.

After deployment to jamoving.co, verify both pages and the sitemap on the public domain. Verify the domain in Google Search Console and submit `https://jamoving.co/sitemap.xml`. Configure a verified Google Business Profile with the same name, phone, website, and genuine service areas. Only publish verified hours, licensing information, reviews, and address details. The schema currently contains only Berkeley locality, not a street address; it does not assert eligibility for Google's LocalBusiness rich results. Rankings and indexing are not guaranteed by these changes.

References: https://developers.google.com/search/docs/appearance/structured-data/local-business and https://support.google.com/business/answer/7091.
